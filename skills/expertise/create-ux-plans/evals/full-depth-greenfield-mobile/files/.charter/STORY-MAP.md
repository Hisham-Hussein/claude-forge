# Story Map: Shelfshare

**Personas:** lender (owns tools, lists them), borrower (needs a tool for a weekend job). Both use the app on their phones, mostly on the move.

**Language:** English only.

## Backbone

| Activity | Tasks |
|----------|-------|
| SM-A1 List a tool | Add a tool; manage my tools |
| SM-A2 Borrow a tool | Find a tool nearby; request it; track my requests |

## Detailed Map

### SM-A1 List a tool

| Release | Story |
|---------|-------|
| **MVP** | SM-001: Add a tool with a name, photo, category and the days it is available |
| **MVP** | SM-002: See my tools and whether each is lent out, requested or free |
| **MVP** | SM-003: Accept or decline a borrow request |
| R2 | SM-004: Set a deposit amount |

### SM-A2 Borrow a tool

| Release | Story |
|---------|-------|
| **MVP** | SM-005: Search tools near me by category and distance |
| **MVP** | SM-006: Open a tool and request it for chosen days |
| **MVP** | SM-007: See my requests and their status (pending, accepted, declined, returned) |
| R2 | SM-008: Rate the lender after returning |

## Release Slices

| Release | Stories | Goal |
|---------|---------|------|
| **MVP** | 6 | A neighbour can list a tool and another can find, request and track it. |
| R2 | 2 | Trust: deposits and ratings. |
